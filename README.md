# 糖尿病診斷與治療決策台

單一檔案的靜態網頁（`index.html`），引導使用者完成糖尿病診斷、分型、個別化血糖目標與治療選擇，並逐條對照台灣健保藥品給付規定。

## 依據

- ADA Standards of Care in Diabetes—2026（第 2、6、9、10、11、13、15 章）
- ADA/EASD Management of Type 2 Diabetes, 2026 consensus
- KDIGO Diabetes in CKD 2022、CKD 2024
- 健保藥品給付規定 第五節 5.1 糖尿病用藥（115.08.21 更新；使用條件 114/6/1）、第二節 2.16 dapagliflozin／empagliflozin 心衰竭與慢性腎臟病（115.9.22 更新）。條文於 2026-10-28 自健保署網站下載核對。

## 分頁

1. 引導評估：輸入檢驗值與病史，即時判讀診斷（含是否需要確認）、分型、個別化目標、指引建議，以及各藥健保給付結果與尚缺條件；可複製摘要
2. 診斷與分型：非孕期與妊娠期標準、確認規則、HbA1c 失真情況、篩檢對象、分型線索
3. 治療選擇：選藥順序、藥物類別比較、胰島素起始、長者
4. 健保給付：5.1 使用條件、各藥條文、指引與健保的落差
5. 流程總覽（目前病人位置會高亮）
6. 教學病例：十個虛構病例，可載入評估並作答（共 20 題）
7. 參考文獻

## 開發

決策邏輯集中在 `index.html` 的 `/*ENGINE-START*/ … /*ENGINE-END*/` 區塊。測試同時核對十個病例的答案與引擎判讀一致：

```bash
node tests.cjs
```
